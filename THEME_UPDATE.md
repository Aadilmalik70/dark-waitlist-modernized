# SERP Strategist - Modern Landing Page 

A professional, modern landing page for SERP Strategist with both **Light** and **Dark** theme options. Built with **Next.js**, **shadcn/ui**, and **Tailwind CSS**.

## 🎨 **Theme Options**

### **Light Theme (Default)** - `/` or `/light`
- **Clean, professional design** with light backgrounds
- **Purple/blue gradient accents** for CTAs and highlights  
- **Glass morphism cards** with subtle transparency
- **High contrast** for excellent readability
- **Perfect for business/enterprise audience**

### **Dark Theme** - `/modern` 
- **Dramatic dark backgrounds** with gradient overlays
- **Outrank-inspired styling** with purple/pink accents
- **Floating UI elements** with atmospheric effects
- **Modern SaaS aesthetic**

## 🔧 **Customization**

### **To Modify Colors:**
Edit `app/globals.css` and `tailwind.config.js` for color palette changes.

### **To Edit Content:**
- Hero content: `components/hero-section-light.tsx`
- Features: `components/features-light.tsx`  
- Pricing: `components/pricing-light.tsx`

### **To Switch Default Theme:**
Change the imports in `app/page.tsx` to use dark components instead.
